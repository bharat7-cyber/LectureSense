# MaViLS Dataset

## Dataset
MaViLS - Matching Videos to Lecture Slides.

## Official Resources

- Original repository:
  https://github.com/andererka/MaViLS

- Dataset download:
  https://www.kaggle.com/datasets/e98bcdecedc67af45204338260556f932f8ec426b81caed0130d2cce80c4ea84

- Research paper:
  https://www.isca-archive.org/interspeech_2024/anderer24_interspeech.pdf

## Dataset Contents

The MaViLS benchmark includes:
- Lecture video recordings
- Audio transcripts
- PDF lecture slides
- Human-labelled slide alignment ground truth

## Download Instructions

1. Open the Kaggle dataset link.
2. Download the required dataset assets.
3. Extract the files locally.
4. Place the files in the directories expected by the LectureSense scripts.
5. Verify the dataset paths before running training or evaluation.
